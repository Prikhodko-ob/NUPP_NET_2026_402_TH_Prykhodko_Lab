# Лабораторна робота №1 — ConstructionCompany
.NET 8, Visual Studio 2022. Відкрийте ConstructionCompany.sln, призначте ConstructionCompany.Console стартовим проєктом, натисніть Ctrl+F5. Або виконайте `dotnet run --project ConstructionCompany.Console`.

## GitHub
Створіть публічний репозиторій NUPP_NET_2026_{Номер групи}_TK_{Прізвище}_Lab з шаблоном .gitignore Visual Studio. Встановіть master як базову гілку (за потреби перейменуйте main). Клонуйте репозиторій, виконайте `git switch -c lab1`, скопіюйте файли проєкту до репозиторію (не замінюйте повний .gitignore GitHub скороченим локальним), запустіть програму, додайте PDF з фактичним результатом. Виконайте `git add .`, `git commit -m "Complete lab 1"`, `git push -u origin lab1`. На GitHub створіть Pull Request lab1 → master.

PDF у цьому архіві містить очікуваний результат, не фактичний запуск: у середовищі підготовки немає .NET SDK. Перед здачею запустіть програму та додайте фактичний вивід у PDF.

## Контрольні запитання
1. Клас — посилальний тип; структура — тип значення. Присвоєння структури копіює її значення, присвоєння класу копіює посилання.
2. Абстрактний клас не можна створити напряму; він може містити абстрактні й реалізовані члени.
3. Інтерфейс визначає контракт; клас може реалізувати кілька інтерфейсів, але успадковує лише один базовий клас. Абстрактний клас може мати стан екземпляра і конструктори.
4. Наслідування дозволяє похідному класу використовувати й розширювати базовий. Модифікатори: public, private, protected, internal, protected internal, private protected.
5. Статичні члени належать типу, звичайні — екземпляру. Статичний конструктор ініціалізує тип.
6. Делегат — типобезпечне посилання на метод; може бути одно- або багатоадресним. Action, Func, Predicate — стандартні узагальнені делегати.
